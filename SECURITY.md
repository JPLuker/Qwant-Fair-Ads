# Security policy

## Supported versions

Only the latest release is supported.

## Report a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/JPLuker/Qwant-Fair-Ads/security/advisories/new). Do not disclose vulnerabilities in public issues.

Reports should identify the affected version, steps to reproduce, and the possible impact. The target acknowledgement time is seven days.

## Security limits

Qwant Fair Ads is a page-layout extension, not a malware scanner. Its click confirmation cannot intercept browser-level context-menu navigation or prove the final destination of a redirect.
